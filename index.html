01 / PENDAHULUAN

Latar Belakang

Alasan pengembangan website informasi sekolah dan aplikasi SIAKAD.

Digitalisasi Informasi Sekolah

Website sekolah menjadi media penyampaian profil, visi misi, fasilitas, berita, pengumuman, informasi lomba, dan kontak sekolah kepada masyarakat.

Pengelolaan Akademik

Aplikasi SIAKAD menyediakan autentikasi pengguna, dashboard, pencatatan data absensi, dan rekap kehadiran siswa.

02 / ANALISIS

Identifikasi Permasalahan

Permasalahan yang menjadi dasar kebutuhan sistem.

Pengelolaan Data

Pencatatan data secara manual membutuhkan waktu dan ketelitian.

Informasi Sekolah

Informasi sekolah perlu disajikan melalui media yang mudah diakses.

Rekap Absensi

Data kehadiran perlu dicatat dan dirangkum secara teratur.

Pengumuman

Penyampaian berita dan pengumuman membutuhkan media publikasi.

03 / SOLUSI

Tujuan dan Solusi Sistem

Tujuan Utama

Membangun media informasi sekolah berbasis web dan aplikasi akademik untuk mendukung pengelolaan kehadiran siswa.

Solusi yang Ditawarkan

  • Website informasi sekolah.
  • Login menggunakan autentikasi pengguna.
  • Dashboard ringkasan kehadiran.
  • Pencatatan data absensi.
  • Penghapusan data absensi.
  • Ekspor data ke format CSV.

12 / PENYIMPANAN DATA

Struktur Data

Data absensi yang digunakan pada implementasi aplikasi.

LocalStorage: absensiSMA

FieldTipe DataKeterangan
namaStringNama siswa
nisnStringNomor induk siswa nasional
kelasStringKelas siswa
tanggalDate/StringTanggal absensi
statusStringHadir, Izin, Sakit, atau Alpa

LocalStorage bukan database server. Data tersimpan pada browser perangkat yang digunakan dan belum otomatis tersinkronisasi dengan perangkat lain.
